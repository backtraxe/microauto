# MicroAuto App Icon

- 画布：512 × 512，圆角 112
- 背景：`#4338CA` → `#0EA5E9` 线性渐变
- 图形：白色键帽，镂空小写 `m`，底部留一层 30% 白色底座
- 占比：约 208 × 240px（约画布 41% × 47%），四周留白约 28%
- Adaptive Icon：前景保持在 72dp 安全区内，背景为渐变
- Monochrome：键帽轮廓 + `m` 线条，用于 Android 13+ 主题图标

## 设计概念

- 产品语义：MicroAuto 的核心动作是“自动按键 / 自动执行”，键帽是最直接的载体。
- 负空间：小写 `m` 从键帽中镂空，既是字标，也让键帽保留实体感。
- 层次：底部 30% 白色底座暗示键帽被按下，不增加颜色层级。
- 小尺寸：48px 下 `m` 仍可辨认；主题图标使用轮廓版本。

`icon.svg` 用于传统 mipmap PNG；`icon-foreground.svg` 用于 Adaptive Icon 前景 PNG。
