# MicroAuto App Icon

- 画布：512 × 512，圆角 112
- 背景：`#312E81` → `#0891B2` 线性渐变
- 图形：小型机器人头像，白色渐变头、深色面罩、琥珀色传感器、白色天线
- 占比：外轮廓约 232 × 238px（约画布 46%），四周留白约 27%
- Adaptive Icon：前景保持在 72dp 安全区内，背景为渐变
- Monochrome：机器人剪影，面罩镂空，用于 Android 13+ 主题图标

`icon.svg` 用于传统 mipmap PNG；`icon-foreground.svg` 用于 Adaptive Icon 前景 PNG。
