# MicroAuto App Icon

- 画布：512 × 512，圆角 112
- 背景：纯色 `#0F766E`，无渐变
- 图形：白色 `M` 单线条，描边 40、圆角端点，右下角琥珀色圆点 `#FCD34D`
- 占比：外轮廓约 240 × 174px（约画布 47%），四周留白约 27%
- Adaptive Icon：前景保持在 72dp 安全区内，背景为纯色
- Monochrome：单色 `M` + 圆点，用于 Android 13+ 主题图标

`icon.svg` 用于传统 mipmap PNG；`icon-foreground.svg` 用于 Adaptive Icon 前景 PNG。
