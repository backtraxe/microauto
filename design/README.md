# MicroAuto App Icon

- 画布：512 × 512，圆角 112
- 背景：`#4338CA` → `#0EA5E9` 线性渐变
- 图形：高架桥，一条上升的白色桥面，下方三根高度递增的桥墩，全白，无箭头与圆点
- 占比：外轮廓约 244 × 232px（约画布 47%），四周留白约 27%
- Adaptive Icon：前景保持在 72dp 安全区内，背景为渐变
- Monochrome：同一条盘山路径，用于 Android 13+ 主题图标

`icon.svg` 用于传统 mipmap PNG；`icon-foreground.svg` 用于 Adaptive Icon 前景 PNG。
