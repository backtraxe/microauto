# MicroAuto App Icon

- 画布：512 × 512，圆角 112
- 背景：纯色 `#0F766E`，无渐变
- 图形：小写 `m` 单线条，描边 36、圆角端点；起点琥珀圆点代表 micro，终点琥珀箭头代表 auto
- 占比：外轮廓约 238 × 207px（约画布 46%），四周留白约 27%
- Adaptive Icon：前景保持在 72dp 安全区内，背景为纯色
- Monochrome：单色 `m` + 圆点 + 箭头，用于 Android 13+ 主题图标

`icon.svg` 用于传统 mipmap PNG；`icon-foreground.svg` 用于 Adaptive Icon 前景 PNG。
