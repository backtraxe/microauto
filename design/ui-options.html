MicroAuto / UI Directions / 2026.10

八套界面方向，
你更想让 MicroAuto 像哪一个？

两轮共八套：前四套是独立气质，后四套是 01 × 02 的明暗与结构重组。每套都包含首页与编辑页，重点展示脚本列表、行内运行、运行状态、代码编辑与日志入口。 这是视觉方向稿，不是最终实现；选定后可以只改主题、布局与组件样式，不动运行时。

01 Midnight IDE 02 Automation Deck 03 Paper & Ink 04 Control Room 1×2 混合方案 → 怎么选
01
Dark / Dense / Developer-first

Midnight IDE

给长期待在编辑器里的人，一间深夜工作室。

深色优先、等宽字体、低饱和的蓝灰层级，强调“运行中”和“代码”本身。首页更像一个轻量 IDE 的项目面板，编辑页则是一块完整的代码工作区。 适合已经熟悉脚本、终端和自动化工具的用户。

02

把脚本当成一张张“自动化卡片”，而不是文件。

1 × 2
Round 02 / Hybrid Directions

把 Midnight IDE 和 Automation Deck 混在一起

同一套骨架，四种明暗分工。

保留 02 的状态卡、运行条和低门槛信息架构，同时借用 01 的深色代码表面、等宽标签和紧凑密度。 下面四套不是简单换色，而是把“什么时候深、什么时候浅、哪里像 IDE、哪里像卡片”拆开重组。

H1Night Deck全深色 · Deck 卡片结构 H2Split Shift浅色首页 · 深色编辑 H3Studio Daylight浅色 IDE · 深色命令栏 H4Flip Deck深色监控 · 浅色写作
H1
All Dark / Deck Structure / Soft Contrast

Night Deck

Automation Deck 的骨架，换成 Midnight IDE 的夜间皮肤。

状态摘要、脚本卡片、运行条和底部导航都保留 02 的亲和力，但底色、卡片和代码区换成 01 的深海军蓝。 比原版 Midnight 更柔和，比原版 Deck 更适合夜间和长时间使用。

H2
Light Library / Dark Focus

Split Shift

白天在浅色书架里挑任务，进编辑页就切到深色专注。

首页保留 02 的浅色卡片、状态摘要和运行条；编辑页直接采用 01 的深色代码工作区。两套表情通过同一条靛蓝强调色和圆角尺度连起来。 这是最像“真实产品”的组合：浏览要轻，写代码要沉。

Why it works
阅读最舒服

深色只负责短时监控，浅色负责长时间阅读和输入；对眼睛和户外使用都更友好。

Trade-off
反差最大

首页和编辑页的明暗关系与 Split Shift 相反，用户第一次进入编辑页会感到“换了一个 App”；需要清晰的空间提示。

Best for
监控 + 写作

适合频繁查看运行状态、但真正写脚本时间较长的用户；也适合作为“监控模式/写作模式”的显式切换。

Decision / 怎么选

不是选“好看”，
是选 MicroAuto 想成为什么。

八套方案共用同一套功能与信息架构：前四套是独立气质，后四套是 01 × 02 的明暗与结构重组。实现成本都落在主题 token、布局和组件样式上，不涉及脚本运行时。

Round 01 / 四个独立方向
方向第一眼最适合代价 / 实现成本
01 Midnight IDE专业、深夜、代码脚本重度用户、开发者新用户门槛高，浅色场景弱成本：中 · 需要完整深色 token 与浅色变体

04 Control Room工业、仪表、队列多脚本、定时、运维型气质偏硬，普通用户可能被劝退成本：低 · 直角/边框/状态条，样式直接
Round 02 / 1 × 2 混合方向
方案明暗分工最适合代价 / 实现成本
H1 Night Deck首页深色 + 编辑深色夜间默认、Deck 用户柔和圆角削弱 IDE 锋利感成本：低 · Deck 布局换深色 token
H2 Split Shift首页浅色 + 编辑深色最像真实产品的默认方案进出编辑页有明显亮度跳变成本：中 · 两套外观 + 转场提示
H3 Studio Daylight首页浅色 + 编辑浅色（深色命令栏）白天主力、喜欢 IDE 密度深色条用多了会割裂成本：中 · IDE 布局浅色化 + 对比条
H4 Flip Deck首页深色 + 编辑浅色监控多、写作时间长明暗关系与 H2 相反，需要模式提示成本：中 · 浅色编辑 + 深色顶底栏
→
如果从 1×2 里选：我建议默认 H2 Split Shift；想要全深色选 H1 Night Deck；想要全浅色但保留 IDE 密度选 H3 Studio Daylight；监控与写作并重选 H4 Flip Deck。

H2 最像真实产品：首页负责“找任务、看状态”，编辑页负责“沉浸写代码”，两边的靛蓝强调色和圆角尺度保持一致。原版 02 Automation Deck 仍然是最稳妥的纯浅色默认，01 Midnight IDE 可以作为它的深色主题。
